# 🇰🇷 Korean-to-Urdu Translator 🇵🇰          link  ➡ https://unitedq25-star.github.io/my-first-project/
 Welcome to my translation project. This application helps users bridge the gap between Korean and Urdu languages
 using JavaScript and External APIs.

Features
* Real-time Translation:  Instantly converts Korean text to Urdu.
* Speech Synthesis:  Listen to the pronunciation of translated text.
* User-Friendly Interface: Clean and responsive design.
* GitHub Pages Hosted:  Easily accessible via browser.

##  Tech Stack
* Frontend: HTML5, CSS3
* Scripting: JavaScript 
* API:  Google Translate API / MyMemory API
* Deployment:  GitHub Pages
